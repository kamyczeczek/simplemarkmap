# Scenariusze UI

## Wejście

Każdy scenariusz opisuje cel, dozwolony adres, kroki, selektory i oczekiwany rezultat.

## Kontrola

Scenariusz musi działać na danych testowych. Przed uruchomieniem na realnej aplikacji człowiek zatwierdza adres i akcje.

## Format

Skopiuj `scenario.template.md`; nie twórz scenariusza od pustego pliku.
