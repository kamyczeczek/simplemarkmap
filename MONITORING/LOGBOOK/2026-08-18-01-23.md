### Bug Fix: Cross-Drive relPath

**Error:** `relPath('C:\proj\a.md', 'D:\other\b.md')` → `../../D:/other/b.md` (invalid relative)

**Fix:** Added drive-letter detection at start of `relPath`:
```javascript
const fromDrive = /^[a-zA-Z]:/.exec(fromFile)?.[0]?.toLowerCase();
const toDrive = /^[a-zA-Z]:/.exec(toFile)?.[0]?.toLowerCase();
if (fromDrive && toDrive && fromDrive !== toDrive) {
    return path.resolve(toFile);
}
```

**Test added:** `tests/test-relpath.js` cross-drive case → returns `D:\other\b.md`
